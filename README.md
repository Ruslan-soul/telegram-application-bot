
# Telegram Application Bot

Telegram-бот для автоматизации сбора и обработки заявок клиентов.

Проект позволяет клиентам отправлять заявки через Telegram, а администраторам — управлять ими, отслеживать статусы, искать нужные обращения и экспортировать данные.

## Возможности

### Для клиентов
- Создание заявки через пошаговую форму.
- Отправка контактного номера через Telegram или вручную.
- Выбор услуги.
- Добавление комментария.
- Подтверждение или отмена заявки.
- Получение уведомлений об изменении статуса заявки.

### Для администраторов
- Просмотр заявок через административную панель.
- Просмотр подробной информации о заявке.
- Изменение статусов заявок.
- Фильтрация по статусам.
- Поиск заявок.
- Пагинация списка.
- Просмотр статистики.
- Экспорт заявок в Excel.
- Создание резервных копий базы данных.

### Дополнительные возможности
- Хранение данных в SQLite.
- Валидация пользовательского ввода.
- Защита от SQL-инъекций через параметризованные запросы.
- Защита Excel-экспорта от внедрения формул.
- Логирование событий и ошибок.
- Автоматическая ротация логов.
- Автоматические резервные копии базы данных.
- Автоматические тесты на pytest.

## Установка и запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/Ruslan-soul/telegram-application-bot.git
cd telegram_bot
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

Для запуска тестов:

```bash
pip install -r requirements-dev.txt
```

### 5. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=your_telegram_id_here
```

- `BOT_TOKEN` — токен Telegram-бота от BotFather.
- `ADMIN_IDS` — Telegram ID администратора.

Не публикуйте `.env` и не передавайте токен третьим лицам.

### 6. Запуск бота

```bash
python main.py
```

## Тестирование

- Файл `.env` исключён из Git.
- База данных и резервные копии не включаются в публичный репозиторий.
- Пользовательские данные проходят валидацию.
- SQL-запросы используют параметры.
- Excel-экспорт защищён от внедрения формул.
